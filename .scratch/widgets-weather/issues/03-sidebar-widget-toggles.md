# 03: "Widgets" toggles in the sidebar

**What to build:** The sidebar gets a "Widgets" group, on every page, with a switch per Widget in the registry. Flipping a switch Shows or Hides that Widget, and the switch always reflects the Widget Board, including changes made elsewhere. Built from the registry, so a new Widget gets its switch automatically.
