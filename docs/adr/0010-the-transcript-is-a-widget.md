# The Transcript is a Widget

The Transcript and the box for typed messages leave the middle of the Jarvis page and become the Transcript Widget, an ordinary built-in, Expandable Widget in the Widget registry, so the Orb and talking by voice have the middle to themselves. Being a Widget, it gets everything ADR 0002 gives every Widget for free: Jarvis shows, hides, moves, expands and collapses it with the same server tools, and the Owner drags it, closes it, and finds it as they left it. Expanded means what it means for any Widget, the full Transcript large in the middle while Push-to-talk keeps working. We considered a fixed panel docked to the page outside the Widget system, but that would be a second way to show and hide things next to the one ADR 0002 set up, and Jarvis couldn't open it when asked.

## Consequences

- With the Transcript Widget Hidden, the Orb shows Captions of the last Turn, so a Session can run by voice alone without losing a Reply, a Memory being Remembered or Forgotten, or an error.
- It has no Widget Settings, and Jarvis only Shows or Hides it when the Owner asks; no Turn Shows it on its own, as Search does with the Results Widget.
- The middle column the Widget Board keeps clear now holds only the Orb and its Captions; it keeps its width so the Spots don't move.
- On a phone, where there are no margins, it is pinned along the bottom edge at full width instead of floating, unlike other Widgets.
